U-CTSC live demo

One child, two companions. Left: Pip as is. Right: Pip + the U-CTSC controller. Every reply is scored by the judge model.
Research demo, not a product, and not for use by children. The companion "Pip" is a small open model (Qwen3-8B) run under a deliberately engagement-seeking prompt, to show the risks studied in the U-CTSC project and how the controller responds. Replies can be inappropriate. Please don't enter real personal information; chats are not stored. Project page: gir-ish.github.io/U-CTSC
